# Blinkit Grocery Sales Analysis – Excel Dashboard

## Project Overview
Analyzed Blinkit grocery sales data using Microsoft Excel to identify sales trends and business insights.

## Key Insights
- Total Sales: $1.20M
- Total Records: 8,523
- Fruits & Vegetables and Snack Foods contributed 29.4% of sales.
- Supermarket Type 1 contributed 65.5% of sales.
- Tier 3 locations contributed 39.3% of sales.
- Low-fat products contributed 64.6% of sales.

## Tools Used
- Microsoft Excel
- Pivot Tables
- Charts and Dashboard

## Objective
To analyze grocery sales performance and support data-driven business decisions.
